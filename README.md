# C++ Reading Quiz · Week 2

A simple, responsive quiz with 27 questions and code examples. Recall or type an answer, reveal the correct answer, then mark it as **Got it** or **Needs practice**. Review missed questions at the end of each round.

Open `index.html` in any modern browser. The entire quiz is a single HTML file with no dependencies, accounts, or build step. Responses are kept in the page only and are not submitted anywhere.

Published with GitHub Pages from the root of the `main` branch.
